# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in TheySay, please report it privately via [GitHub Security Advisories](https://github.com/laike9m/TheySay/security/advisories/new) or by emailing **laike9m@gmail.com** rather than opening a public issue.

All local credentials and platform sessions in TheySay are stored exclusively on the user's device and are never transmitted to any external servers.
